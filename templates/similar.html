How weights work

Oracle text is always scored, using IDF-weighted overlap — rare terms like "storm" count more than common terms. The score is normalized so results are comparable regardless of how many factors are active.

Each optional factor (Types, Keywords, Subtypes, Color Identity) uses Jaccard similarity — shared terms divided by total terms. Mana Value uses proximity: closer MV = higher score.

The weight is a multiplier. A factor weighted 2 counts twice as much as one weighted 1. Setting a weight to 0.1 makes it barely influence results. No single "right" setting — tune, update, and see what surfaces.

MTG filter removes ubiquitous terms (creature, target, player, graveyard, battlefield…) from the oracle text match. Cards won't score higher just because they both mention "target creature". Try toggling this to see which mode gives better results for a given card.

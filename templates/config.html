Search Logic

Default similarity methods used by each tool. The standalone Similarity tool and Commander Eval each have their own setting.

Semantic: Uses AI embedding vectors to find cards with similar meaning — catches reworded abilities, mechanical cousins, and conceptually similar designs. Requires the embedding index to be built.
Legacy: Classic TF-IDF word-overlap search with tunable factor gates. Works without embeddings.
Controls the "Find Similar" search on the Commander Eval page when looking for similar legendary commanders.

Pricing

Default pricing source used for deck cost calculations. Prices are fetched from Scryfall and cached on disk for 24 hours.

Each deck can override this with its own pricing source via the Deck Builder's dropdown.

Deck History

Tracks card additions and removals to help you review deck changes. A reminder will appear when a deck has gone this long without changes.

After this many days with no deck changes, you'll be reminded to review and optionally clear the history. Default 30 days.

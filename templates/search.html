Search tips

Text Search matches card name, type line, and rules text. Comma-separate multiple terms (e.g., draw, discard) — cards must match ALL terms.

Name / Oracle Text are separate fields for precision. Oracle Text also supports comma-separated AND logic.

Type Line uses an em-dash between card type and subtype (e.g., Creature — Human). You can type a regular hyphen and it'll still match.

Keywords are comma-separated with AND logic (cards must have ALL keywords listed).

Colors uses WUBRG order. "At most" means the card's colors are a subset of your selection.

Mana Value supports ranges like 1-3 in addition to operators.
